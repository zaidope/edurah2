Connect Edurah to Supabase

This package is frontend-connected to the Edurah Supabase/RAH architecture. Add your project's browser-safe URL and anon/publishable key.

Backend setup

Run the included backend/supabase.sql in Supabase SQL Editor, then deploy the RAH Edge Functions and set OPENAI_API_KEY and optional OPENAI_MODEL secrets.

supabase functions deploy rah-intelligence
supabase functions deploy rah-speech
supabase functions deploy rah-chat
